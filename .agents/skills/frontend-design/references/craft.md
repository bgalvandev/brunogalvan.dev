# Portfolio craft criteria

These are review criteria, not a requirement to redesign the existing site.

- Typography: preserve clear headline/body/metadata roles. Use comfortable reading
  line lengths and line height; emphasize with weight and hierarchy before adding
  new sizes. Test Spanish wrapping and browser zoom.
- Layout: keep spacing within groups smaller than spacing between groups. Align
  shared edges and allow the content to determine responsive breakpoints. Avoid
  decorative cards that imply relationships or actions that do not exist.
- Color: use semantic tokens. Verify readable contrast in both themes and do not
  encode state with hue alone. Spend the accent on meaningful emphasis and focus.
- Motion: favor transform/opacity for entrances and short transitions for repeated
  controls. Content must remain readable with reduced motion and without animation.
- Interaction: preserve keyboard focus, accessible names, and predictable targets.
  Never make a non-linked project look actionable. Match loading geometry to the
  completed surface only when data is actually asynchronous.
